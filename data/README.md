# Data

The CSV files are not stored in git (about 91 MB). Download them from Kaggle and put them here:

| File here | Kaggle dataset | File to download |
|---|---|---|
| `youtubers.csv` | https://www.kaggle.com/datasets/praneshmukhopadhyay/youtubers-saying-things | `data.csv` (rename) |
| `mrbeast.csv` | https://www.kaggle.com/datasets/thedevastator/mrbeast-transcribed-youtube-videos | `mrbeast.csv` |
| `INvideos.csv`, `IN_category_id.json` | https://www.kaggle.com/datasets/datasnaek/youtube-new | same names |

All three are CC0 (public domain). You only need them to retrain: the trained model is already in `models/scriptdoctor.joblib`.
